### 🚀 Featured Creations

Here are a few projects I'm proud of. You can find more on my repositories tab!

<br>

**1. OMR Evaluation App**
- **What it is:** A desktop application to automatically scan, detect, and grade OMR (Optical Mark Recognition) sheets from an image.
- **Tech Stack:** Python, **OpenCV** (for image processing, contour detection, and bubble reading), and **Tkinter** (for the GUI).

**2. ParkEase - Smart Parking System**
- **What it is:** A computer vision-based system that monitors a parking lot via video feed, identifies empty and occupied spots in real-time, and displays the status on a simple dashboard.
- **Tech Stack:** Python, **OpenCV**, **YOLO** (for vehicle detection), and **Flask** (to serve the real-time data).

**3. Personal Fitness Tracker**
- **What it is:** A full-stack web application to help users log their daily workouts, track their progress over time, and visualize their fitness journey.
- **Tech Stack:** **React** (for the frontend), **Node.js** & **Express** (for the REST API), and **MongoDB** (for data storage).
